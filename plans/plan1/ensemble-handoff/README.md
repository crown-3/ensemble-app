# Ensemble 디자인 핸드오프

Ensemble 앱의 화면 디자인과 기획서를 담은 패키지입니다. 구현을 시작하기 전에 `PRODUCT_SPEC.md`를 먼저 읽습니다.

## 폴더 구성

```
ensemble-handoff/
├── README.md               이 문서. 디자인 파일을 읽는 방법
├── PRODUCT_SPEC.md         기획서. 개념, 기능, 데이터 모델 초안, 확인할 질문
├── screens/                화면 12개의 디자인 원본
├── wireframe/              기획자가 그린 최초의 레이아웃 스케치
├── assets/logo.png         로고 (252×264, 흰 배경)
├── tokens/tokens.json      Glassline 디자인 시스템의 토큰
└── tokens/DESIGN_SYSTEM.md Glassline 디자인 시스템의 사용 규칙
```

## 화면 파일을 읽는 방법

`screens/*.dc.html` 파일은 디자인 도구의 전용 형식입니다. 브라우저에서 단독으로 열리지 않으므로 **실행하지 말고 명세로 읽습니다.** 구현에 그대로 복사해서 쓰는 코드가 아닙니다.

- **마크업은 `<x-dc>` 태그 안에 있습니다.** 모든 요소의 스타일이 인라인 `style` 속성에 적혀 있으므로, 색상, 간격, 글자 크기, 모서리 반경을 수치 그대로 읽을 수 있습니다.
- **`<helmet>` 안의 내용은 문서의 `<head>`에 들어가는 것입니다.** 폰트 링크와 기본 스타일, 좁은 화면용 미디어 쿼리가 있습니다.
- **`{{이름}}` 은 데이터가 들어가는 자리입니다.** 값은 파일 맨 아래의 `<script type="text/x-dc">` 안에 있는 `renderVals()`가 반환합니다.
- **`<sc-for list="{{목록}}" as="항목">` 은 반복입니다.** 안쪽 마크업이 목록의 항목마다 한 번씩 그려집니다.
- **`<sc-if value="{{조건}}">` 은 조건부 표시입니다.**
- **`onClick="{{ 함수 }}"` 는 클릭 동작입니다.** 함수의 내용은 `renderVals()`에 있으며, 어떤 상태가 바뀌는지 확인할 수 있습니다.
- **`<a href="다른화면.dc.html">` 은 화면 이동입니다.** 화면 사이의 이동 관계를 이 링크로 파악할 수 있습니다.
- **`./support.js` 는 디자인 도구의 런타임이며 이 패키지에 없습니다.** 무시합니다.
- **로고 경로는 `../assets/logo.png` 로 바꾸어 두었습니다.** 원본에서는 디자인 도구 내부의 경로였습니다.

화면 속의 에이전트 이름(서윤, 도윤, 한서, 지안, 태오), 프로젝트 이름, 채팅 내용, 사용량 수치, 폴더 경로는 모두 예시 데이터입니다. `[초기화 시각]`처럼 대괄호로 감싼 글자는 실제 값을 정하지 못해 비워 둔 자리입니다.

## 화면별 상태

| 파일 | 동작하는 부분 | 정적으로 그린 상태 |

| `NewChat.dc.html` | 에이전트 카드 선택과 해제, 선택 요약 문구 | |
| `ProjectMemory.dc.html` | | 두 번째 항목이 수정 중인 상태 |
| `AgentEdit.dc.html` | | 이력의 두 번째 항목이 수정 중인 상태 |
| 그 밖의 화면 | | 전부 정적 |

메인 채팅의 "에이전트 초대" 버튼은 `InvitePopover`, 멤버 패널의 내보내기 버튼은 `RemoveDialog`, 파일 카드의 "열기" 버튼은 `Viewer`, 사이드바의 프로젝트 추가 버튼은 `NewProject`를 여는 것으로 의도했습니다. 디자인 파일에서는 이 연결을 구현하지 않았습니다.

## 디자인 시스템

Glassline이라는 디자인 시스템의 라이트 테마를 사용했습니다. 규칙은 `tokens/DESIGN_SYSTEM.md`에, 값은 `tokens/tokens.json`에 있습니다. 화면 파일에는 토큰 이름이 아닌 실제 값이 적혀 있으므로, 구현할 때 아래 표로 토큰과 대응시킵니다.

| 용도 | 토큰 | 값(라이트) |
|---|---|---|
| 채팅 영역 배경 | `surface-window` | `#ffffff` |
| 양쪽 패널 배경 | `surface-sidebar` | `#f1f1f3` |
| 상단 줄, 입력창 줄 | `surface-glass` + 24px 블러 | `rgba(250,250,252,0.78)` |
| 팝오버, 대화상자, 일반 헤더 | `surface-glass-tinted` | `#f7f7f9` |
| 구분선 | `separator` | `#dedee2` |
| 본문 글자 | `ink` | `#1d1d1f` |
| 보조 글자 | `ink-secondary` | `#636368` |
| 강조 채움 | `accent` | `#0a6ae0` |
| 링크와 글자 버튼 | `accent-text` | `#0a62d0` |
| 에이전트 말풍선 | `bubble-received` | `#e9e9ec` |
| 입력 필드 테두리 | `field-border` | `#8a8a8f` |
| 위험한 동작 | `danger` | `#c9001a` |
| 작업 중 상태 점 | `bubble-fallback` 값을 사용 | `#1b7f37` |

- **강조색의 사용처:** `accent`는 사용자의 말풍선, 사이드바에서 선택된 항목, 주요 버튼, 읽지 않음 표시에만 사용합니다. 그 밖의 선택 상태(탭, 필터, 목록)는 `#e9e9ec` 배경이나 `ink` 색 밑줄로 표현했습니다.
- **글꼴:** Asta Sans(Google Fonts)를 사용하며, 굵기는 400, 600, 700만 사용합니다. 본문은 13px입니다.
- **모서리 반경:** 사이드바 항목과 입력 필드는 8px, 카드와 팝오버는 14px, 말풍선과 입력창은 17px, 버튼과 아바타는 완전한 원형입니다.
- **다크 테마:** 토큰에는 다크 값이 있지만, 화면은 라이트 테마만 그렸습니다. 앱 설정에 테마 전환이 있으므로 색상은 토큰 변수로 구현합니다.
- **디자인 시스템에 없어서 직접 정한 값:** 멘션 강조(`#d6e6fb` 배경, `#0a4fa8` 글자), 아바타의 배경 색조(`#dfe6f1`, `#e8e2d6`, `#dde9e1`, `#eadfe6`, `#e3e3ea`)입니다.

## 알려진 한계

- 디자인 파일은 렌더링 결과를 검증하지 않은 상태로 전달되었습니다. 겹침이나 어긋남이 있을 수 있으므로, 수치는 참고하되 구현 화면을 직접 확인합니다.
- 로고 이미지는 배경이 흰색입니다. 회색 사이드바 위에서는 `mix-blend-mode: multiply`로 배경을 숨겼습니다. 다크 테마에서는 이 방법이 통하지 않으므로 배경이 투명한 로고가 필요합니다.
- 좁은 화면에서는 패널을 세로로 쌓는 간단한 규칙만 넣었습니다. 모바일 화면은 설계하지 않았습니다.
