# Ensemble 결정 사항

`ensemble-handoff/PRODUCT_SPEC.md` 7절의 질문에 대한 기획자의 답변입니다. (2026-10-05)

| # | 질문 | 결정 |
|---|---|---|
| 1 | 기술 스택 | Electron + React + TypeScript |
| 2 | 에이전트 세션 실행 방식 | 각 도구의 CLI(`claude`, `codex`, `gemini`)를 자식 프로세스로 실행하고, JSON 스트림 출력을 읽어 채팅 요소로 바꿉니다. |
| 3 | 멘션이 없는 메시지의 응답자 | 리더 한 명만 응답합니다. 리더는 다른 에이전트를 @멘션해서 일을 넘길 수 있습니다. |
| 3-1 | 리더 지정 | 새 채팅 화면에서 직접 지정합니다. 채팅 중에는 멤버 패널에서 바꿉니다. |
| 4 | 에이전트끼리 대화가 멈추는 조건 | 사용자가 멈출 때까지 계속합니다(@멘션이 더 없으면 자연스럽게 멈춤). 횟수 제한은 없습니다. 정지 버튼을 항상 보이게 둡니다. |
| 5 | 프로젝트 밖 채팅의 메모리 | 없습니다. 그 채팅의 대화 내용만 기억합니다. |
| 6 | 메모리와 이력의 기록 | 메모리는 에이전트가 도구(MCP)로 스스로 기록합니다. 이력은 앱이 에이전트의 활동을 자동으로 기록합니다. |
| 7 | [가정] 항목 | 전부 그대로 진행합니다. |

## 구현 단계

- **1단계(핵심 루프):** Electron 골격, 로컬 저장소, 에이전트 만들기와 편집, 새 채팅, 메인 채팅, Claude Code CLI 연결
- **이후:** 프로젝트와 메모리, 결과물 탭과 뷰어, 앱 설정과 커넥터, Codex와 Gemini 어댑터
